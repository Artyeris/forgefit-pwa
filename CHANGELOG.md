# Changelog

## 0.1.0 — 6 November 2026

Initial independent workout PWA test build.

Dashboard, weekly targets, six editable home-training routines plus Active Rest, 56-exercise library and custom entries, focused set logger, previous-performance prefill, warm-up/drop sets and RIR, rest/elapsed timing, session notes, editable history, basic progress views, themes, JSON backups and restore review, local import recovery snapshot, IndexedDB/journal implementation, offline shell and safe-update prompt, install/help/diagnostics screens.

Original branding and icons. No imported MacroFactor assets, account integration, or proprietary coaching. No fabricated workout history. Zero runtime dependencies.

Validation: 40 domain tests, 5 static-package checks, and 24 explicit memory-adapter UI scenarios passed. Native persistence, actual offline cold launch, updates on a real browser, and physical iPhone installation remain unvalidated. See docs/TEST-REPORT.md.

# ForgeFit 0.1.0

A privacy-first, offline-capable workout tracker PWA. Built as an original iPhone-friendly project, with local data storage, routines, logging, history, and backup/restore.

The production PWA is deployed from the `site/` directory. For Cloudflare Pages, connect the repository and use `site` as the output directory.

**Status:** initial release files are being published. Do not rely on this repository as a live workout-history backup.
